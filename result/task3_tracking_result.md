## 目标结构（视频分析结论）

- 风车中心为 **R 标**：橙色圆环（约 75–90px）内嵌 R 字实心块，随相机运动而移动；
- **扇叶**：绕 R 标旋转的弧形灯串（一串小亮点），外端为 **扇叶圆**（约 18–25px 的圆形亮块）；
- **亮起目标**：被激活叶片的灯串与扇叶圆高亮（V>170）；未亮叶片为暗橙色；
- 小能量机关为 1 个风车（task_3），大能量机关为 2 个并排风车（task_4，如第 1350 帧 R 标位于 (733,528) 与 (1104,614)），两视频中相机均有大幅运动（平摇/移动）。

## 检测方法

每帧执行以下流水线（全部阈值按两段视频统计标定）：

1. **橙色掩膜**：HSV 中 `H∈[0,35], S≥30, V≥30`，3×3 椭圆核闭运算；
2. **R 标检测**：在掩膜连通域中找"圆环 + 中心实心块"组合——环状区域（存在内轮廓、尺寸 40–160px、填充率 0.25–0.70）附近存在紧凑小实心块（R 字，尺寸为环的 0.12–0.50 倍），二者组合才视为 R 标；
3. **高亮元素**：`V>170` 与橙色掩膜求交，7×7 闭运算合并灯串小点后取连通域；
4. **元素划分**：每个高亮元素归属最近的已确认 R 标（大能量机关两风车互不干扰）；
5. **扇叶圆解算**：在距 R 标 0.30–4.60 倍环尺寸的环带内，取**最远端**的紧凑亮块（填充率 ≥0.4、长宽比 <1.9、尺寸为环的 0.18–0.55 倍）为扇叶圆，并要求其内侧存在灯串（低填充元素，位于扇叶圆与 R 之间且在扇叶圆附近）；若无独立扇叶圆（远视距/形态学合并），取整条亮带离 R 最远的端点；
6. **装甲灯条排除**：场地装甲灯条为成对细长竖条（长宽比 ≥3.5 成对出现），与叶片单一弧带区分，避免误检。

## 中心跟踪（跟随中心变化）

- R 标按帧检测，并维护跟踪：检测与跟踪做最近邻关联（阈值 150px），**全局位移**取各匹配对位移的中值，作为相机运动的估计；
- 检测缺失的帧用全局位移外推（无匹配时按 0.85 指数衰减），相机平移期间中心仍被持续跟随；
- 目标角度一律用**当前 R 标位置**计算：`θ = atan2(扇叶圆−R标)`，不使用固定图像坐标代替移动中心。

## 锁定与重选规则

- **身份锁定**：每个 R 标（风车）至多绑定 1 个目标槽位（大能量机关 2 个风车各 1 个）。目标首次有效出现（同一 R 标连续 2 帧检出）即分配 ID 并锁定；
- **关联依据**：目标位置使用 **R 标相对坐标**（`rel = 扇叶圆 − R标`），逐帧与槽位的 rel 做最近邻关联，阈值 `max(45px, 0.65×环尺寸)`（rel 坐标天然抵消相机平移，叶片自转仅 ~2–6px/帧）。**不使用轮廓列表顺序作为 ID**；
- **保持身份**：目标持续有效可见期间，即使另一目标出现也不更换 ID；短暂遮挡/漏检时标记 `lost`，位置用末次有效 rel 保持显示；
- **丢失容忍**：`LOST_TIMEOUT = 20` 帧（约 0.67s）。丢失期间保留 ID 等待恢复；恢复时若 rel 仍在关联阈值内则**同 ID 复活**（过期槽位保留 120 帧）；
- **重选条件**：①目标持续丢失 ≥20 帧；或 ②检测到新亮起叶片且其 rel 位置与当前目标不匹配（目标熄灭换叶）。满足后允许选取新目标并分配新 ID。重选是"熄灭换叶/长时间丢失"的受控行为，不是每帧重新初始化。

## 已知失败情况

1. **快速运镜期间的丢失**：相机大范围平移/旋转时伴随运动模糊，R 标或灯串的 HSV 特征瞬时退化，造成数帧到十几帧的 `lost` 标记；全局位移外推与同 ID 复活机制使多数丢失在恢复后保持原 ID；
2. **运镜扫过其他机关/场地元素**：两段视频的运镜过程中会短暂扫过另一台能量机关及场地装甲灯条。装甲灯条对已做形态排除；另一机关被检测时可能短暂建立临时槽位（随后按丢失规则清空），不影响主目标的 ID 连续性；
3. **叶片熄灭期**：能量机关换叶时旧目标熄灭、新叶片亮起，按重选规则换新 ID——这是任务定义的正常重选情形，与无理由跳变区分；
4. **远视距**：机关在画面中很小时（R 环 <40px），R 标特征不可靠，不强行检测，按丢失处理。
